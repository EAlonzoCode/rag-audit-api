## Problema

Consultar normativas de TI (NIST, OWASP, ISO resumen) es lento y propenso a respuestas sin trazabilidad. Esta API expone un pipeline RAG con **respuestas siempre citadas** a fragmentos concretos de los documentos indexados, pensado para flujos de auditoría y gobernanza de IA.
